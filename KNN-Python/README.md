# 🧠 K-Nearest Neighbors (KNN) from Scratch in Python

A simple, clean, and fully functional implementation of the **K-Nearest Neighbors (KNN)** algorithm using only core Python and NumPy.

---

## 📚 Overview

**K-Nearest Neighbors (KNN)** is a **lazy learning**, **non-parametric** algorithm used for classification and regression. It works by storing the entire training dataset and classifying new samples based on the majority vote (or average in regression) of the `k` nearest data points.

---

## 🚀 Features

- ✔️ Implemented from scratch using Python and NumPy
- ✔️ Supports classification
- ✔️ Customizable number of neighbors (`k`)
- ✔️ Simple and well-commented code
- ✔️ Easy to plug into small projects or expand for learning purposes
